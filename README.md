# 🍔 Gastronomic Dream

> Um guia gastronômico web desenvolvido para descobrir, filtrar e partilhar experiências em restaurantes, cafés e estabelecimentos locais.

---

## 🚀 Sobre o Projeto

O Gastronomic Dream nasceu da vontade de criar uma ferramenta prática e intuitiva para quem adora explorar novos lugares para comer. O site permite aos utilizadores pesquisar estabelecimentos, aplicar filtros avançados por especialidade, horário ou modalidade, visualizar avaliações detalhadas (com sistema de meia-estrela) e gerir os seus restaurantes favoritos diretamente no navegador.
Vale ressaltar que ele é apenas um projeto com finalidade de praticar e se aperfeiçoar, e não fins comerciais.

## ✨ Funcionalidades

- **🔍 Sistema de Busca Duplo:** feito tanto para dispositivos móveis quanto para computadores.
- **🎯 Filtros Dinâmicos:** Filtre rapidamente por especialidade, modelo de atendimento ou modalidade.
- **⭐ Sistema de Avaliação:** Exibição de notas com suporte visual de estrelas SVG.
- **💾 Persistência de Dados (Local Storage):** Guarda a lista de restaurantes favoritos e o histórico de pesquisas diretamente no dispositivo do utilizador.
- **📱 Design Responsivo:** Interface adaptada para telemóveis, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais, focando em performance, boas práticas de código e semântica:

- **HTML5** (Estruturação semântica e acessível)
- **CSS3** (Estilização moderna, variáveis e layout responsivo)
- **JavaScript (Vanilla)** (Lógica de pesquisa, manipulação do DOM e gestão de estado com `localStorage`)
